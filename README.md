# Stockify - Landing Page

This is the landing page for **Stockify**, an AI-powered stock price detector that helps investors predict market movements and make informed trading decisions using advanced machine learning models.

## Tech Stack

- **Frontend**: React 18+ with Vite
- **Styling**: Tailwind CSS
- **Build Tool**: Vite with HMR
- **Linting**: ESLint
- **Package Manager**: npm

## Getting Started

```bash
npm install
npm run dev
```
